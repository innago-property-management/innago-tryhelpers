# Either&lt;TLeft,TRight&gt; structure

An Either is a monad that contains exactly one value, either of type TLeft or of type TRight. It can be used to make writing code that is more functional easier. You can use it as a return type in switch expressions, e.g.

```csharp
Either<string, int> either = obj switch
{
    string s => s,
    int n => n,
    _ => default,
};
```

You can also utilize it to apply different functions that produce the same return type, e.g.

```csharp
int eitherMap = either.Map(StringHash, IntHash);
```
